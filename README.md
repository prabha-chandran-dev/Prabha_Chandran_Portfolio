````markdown
## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **Animation:** Framer Motion, React Tsparticles, Confetti JS, React Howler
- **Carousel:** SwiperJS
- **Media Viewer:** React Image Gallery
- **Sound Effects:** Howler.js
- **Icons:** React Icons
- **Routing/State:** React Hooks, useState, useRef
- **Deployment:** Vercel / Netlify (based on your deployment)

## 📁 Folder Structure

```bash
````
